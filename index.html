How I build

The same loop every time, whether it's Assembly, a SQL schema or a RAG pipeline.

  1. Understand the problem

    Break the requirement down to its core logic first: what data moves, what state changes, what can break.

  2. Design the structure

    Choose the architecture before coding: layered systems, normalized schemas or patterns like Repository.

  3. Build and test

    Write clean OOP and test each module on its own, from collision handling to SQL triggers.

  4. Refine and ship

    Handle edge cases, document the logic and deploy, from a console binary to a single file on Vercel.
